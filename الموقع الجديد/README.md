# الموقع الجديد

موقع مطابع روعة التصاميم بالتصميم الجديد اللي طلبه العميل: صفحة رئيسية طويلة بترتيب الموقع المرجعي
(شريط علوي، هيدر فيه اسم المطبعة ومسؤول المبيعات، واجهة بفيلم، شريط متحرك، ١٦ قسم، أعمالنا، عن المطبعة، خطوات الطلب، تواصل، فوتر)،
وصفحة لكل قسم وصفحة لكل منتج، بهوية المطبعة ونصوصها وصورها.

**الرابط المباشر:** https://engmohammad-hash.github.io/rd-amazing-nidal/ (والإنجليزي تحت `en/`)

## الأقسام والمنتجات

الأقسام الـ١٦ ومنتجاتها الـ٩٢ من قائمة المطبعة نفسها (صور الواتساب اللي بعتها العميل).

- **الرئيسية:** كرت لكل قسم (صورة واسم وعدد المنتجات)، بيفتح صفحة القسم.
- **صفحة القسم** `services/<القسم>/`: اسم القسم وجملة عنه وملاحظته المميزة بنجمة، ثم كرت لكل منتج فيه زرين:
  «اطلب الآن» (بيفتح واتساب برسالة ترحيبية فيها اسم المنتج والقسم) و«شاهد منتجاتنا لـ …» (بيفتح صفحة المنتج).
- **صفحة المنتج** `services/<القسم>/<المنتج>/`: فوق نفس كلام الكرت وزر الطلب، وتحت ٢–٣ صور بتكبر بالضغط، ثم المنتج السابق والتالي وباقي منتجات القسم.

البيانات بـ `src/data/site.ar.json` تحت `services` (والإنجليزي بنفس الترتيب بـ `site.en.json`)؛ لكل منتج `id` و`name` و`short` و`img`.
الصور بتنكتب كـ `photo/12` (صور المطبعة الحقيقية)، `shop/bags-01` (رسومات المتجر)، `p/tshirt-01` (رسومات المنتجات).
صور المطبعة الحقيقية بتجهز من مجلد العميل بـ:

```bash
python -I tools/photos.py "../صور و فيديوهات منشان تصميم الفيديو"
```

ورسومات المنتجات (١٣٣ صورة، ثلاثية الأبعاد بألوان المطبعة واسمها) من `src/products/` (كل ملف مجموعة: ورقيات، تغليف، أقمشة، هدايا، لوحات)،
والسيرفر المحلي شغال:

```bash
python -I tools/render_products.py tshirt,cap
```

(أو `all` للكل). لما توصل صور حقيقية لمنتج، بتنحط بـ `src/static/img/photos/` وبيتغير اسمها بـ `img` المنتج.

## المتجر الإلكتروني

صفحة `shop/` (والإنجليزي `en/shop/`): ٢١ منتج بسبع فئات، لكل منتج ٣ صور وخيارات (الورق، التشطيب، المقاس…) وأقل كمية.

- **تصفية وبحث وترتيب:** أزرار الفئات، وبحث بيفهم اختلاف الكتابة (أ/ا، ة/ه، ى/ي)، وترتيب حسب الاسم.
- **العين (نظرة سريعة):** صور المنتج، اختيار الخيارات والكمية، أضف للسلة، المفضلة، استفسار واتساب، ومشاركة رابط المنتج (`shop/?p=<id>` بيفتحه مباشرة).
- **المفضلة (القلب) والسلة:** بالهيدر بكل الصفحات مع العدد، ومحفوظين بمتصفح الزائر.
- **تأكيد الطلب عبر واتساب:** السلة بتنبعت كرسالة مرتبة لرقم المطبعة: المنتجات وخياراتها وكمياتها، والاسم وطريقة الاستلام والملاحظات.
- **الأسعار:** "حسب الكمية" لأن العميل ما عطى أسعار؛ المطبعة بترد بالسعر على واتساب.

المنتجات والفئات والخيارات بـ `src/data/site.ar.json` تحت `shop` (والإنجليزي بنفس الترتيب بـ `site.en.json`)، والصور بـ `src/static/img/shop/`.
الصور حالياً من رسومات الموقع الأول، وبتنبدل بصور منتجات المطبعة الحقيقية.

## الملفات

```
src/
  data/site.ar.json   كل المحتوى بالعربي: بيانات المطبعة، الأقسام الـ١٦ ومنتجاتها، الأعمال، عن المطبعة، الخطوات
  data/site.en.json   النصوص الإنجليزية فقط، فوق العربي بنفس الترتيب
  data/ui.ar.json     كلمات الواجهة وعناوين الأقسام بالعربي
  data/ui.en.json     نفسها بالإنجليزي
  templates/          home.html وsection.html (القسم) وproduct.html (المنتج) وshop.html و404.html، وpartials (الهيدر والفوتر والكروت والأيقونات)
  static/             css و js والخطوط واللوغو وصور الأعمال والفيلم (تُنسخ إلى docs/assets)
  video/              مشهد فيلم الواجهة (hero.js) وصفحة رسمه (render.html)
  products/           رسومات المنتجات ثلاثية الأبعاد وصفحة رسمها (render.html)
  build.py            يبني الموقع في docs/
docs/                 الموقع المبني، وهو اللي بيتنشر
tools/
  publish.py          ينشر الموقعين على الفرع gh-pages: هذا على الجذر، والموقع الأول تحت v1/
  serve.py            سيرفر محلي على 8767: يعرض الموقع ويستقبل كادرات الفيلم
  render_video.py     يرسم الفيلم بـ Edge مخفي ويحوّله لفيديو mp4
  shoot.py            صور شاشة للصفحة كاملة (لابتوب أو موبايل، فاتح أو داكن)
  photos.py           يجهز صور المطبعة الحقيقية للموقع (كاملة وقصّات 4:3)
  render_products.py  يرسم صور المنتجات بـ Edge مخفي ويقص مصغّراتها
```

## تعديل النصوص والنشر

عدّل ملفات `src/data/` ثم ابنِ الموقع:

```bash
python -I src/build.py
```

بعد الـ commit والرفع على main، انشره:

```bash
python -I tools/publish.py
```

## فيلم الواجهة

فيلم من صور وفيديوهات المطبعة الحقيقية اللي بعتها العميل، بالترتيب اللي حطّه: واجهة المحل، ثم ١ لـ ٢٠، ثم الواجهة مرة تانية
وبيخلص على نفس الكادر اللي بيبلش فيه، فالتكرار ما بيبين. بدون صوت (بس لمعة خفيفة على لوحة المحل).
هو خلفية أعلى الصفحة الرئيسية كلها، بنسختين: عريضة للابتوب (1600×900، الصور الطويلة على اليسار فوق نسخة مغبّشة منها)
وطويلة للموبايل (720×1280، الصور العريضة فوق). فوقه ظل بلون الصفحة نفسها، بيج بالفاتح وعنابي بالداكن، بجهة الكلام.

الفيلم بيبلش أول ما يوصل أول جزء منه (ما بيستنى ينزل كامل)، وبيشتغل عند كل الزوار حتى لو الجهاز طالب "تقليل الحركة"
أو "توفير البيانات"، لأن العميل بدو ياه يتحرك دايماً. وبيوقف لحالو لما تنزل تحته.

المصدر: مجلد «صور و فيديوهات منشان تصميم الفيديو» بجذر المشروع (مو بـ git، الأرقام = الترتيب، و0.jpg الواجهة)،
بينسخ لـ `tools/out/showreel-src/`، والرسم بـ `src/video/showreel.html`:

```bash
python -I tools/render_video.py --film=showreel
```

بيكتب `hero-desktop.mp4` و`hero-mobile.mp4` (وأول كادر من كل وحدة) مباشرة بالموقع. أفلام قديمة جربناها: `--film=hero` (اسم المطبعة بالذهب، مرسوم بالكامل)
و`--film=reels-a` / `--film=reels-b` (من ريلز الإنستغرام، بيطلعوا بـ `tools/out/review/`).

## التشغيل محلياً
