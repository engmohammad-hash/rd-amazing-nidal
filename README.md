# مطابع روعة التصاميم .. طباعة شاملة (RD Amazing)

موقع مطبعة **مطابع روعة التصاميم** في الدمام، المملكة العربية السعودية.
المرحلة الحالية: موقع ثابت (HTML/CSS/JS)، وبعدها يتحوّل إلى PHP + MySQL مع لوحة تحكم بنفس التصميم حرفياً.

**الموقع مباشر:** https://engmohammad-hash.github.io/rd-amazing-nidal/

|---|---|---|
| الرئيسية | `/` | فيلم سكرول (صمّم ← اطبع ← فخامة ← استلم)، المنتجات، لماذا نحن، خطوات العمل، رؤية ٢٠٣٠، آراء |

| صفحة كل منتج | `/products/<slug>/` | فيلم سكرول خاص بالمنتج، المواصفات، أزرار الطلب، معرض ٦ صور، منتجات أخرى |
| أعمالنا | `/works/` | معرض كل الصور مع تصفية حسب المنتج وعرض مكبّر |
| من نحن | `/about/` | القصة، ما يميّزنا، رؤية ٢٠٣٠، خطوات العمل |
| آراء العملاء | `/reviews/` | آراء (تجريبية حالياً) |

المنتجات السبعة: كروت شخصية، بوكسات بخور، بوكسات حلويات، أكياس فاخرة، دعوات زفاف ومناسبات، أكواب ورقية مطبوعة، ستيكرات وملصقات.
صور المنتجات حالياً مرسومة بالكود (توضيحية)، وستُستبدل بصور الأعمال الفعلية.

## المحتوى

```
src/
  data/site.json      كل النصوص والبيانات: الاسم، الأرقام، ساعات العمل، المنتجات، الآراء، الأسئلة
  templates/          قوالب الصفحات (Jinja2): base + partials + صفحة لكل نوع
  static/             css و js والصور (تُنسخ إلى docs/assets)
  scenes/             مشاهد Three.js: common.js (المسرح)، kit.js (الكروت والعلب)، story.js (الرئيسية)، ومشهد لكل منتج
  render.html         يرسم مشهداً كادراً كادراً ويحفظه
  build.py            يبني الموقع كاملاً في docs/
docs/                 الموقع المنشور (GitHub Pages يقرأ من هنا)
  frames/<مشهد>/      كادرات الفيلم: desktop (1600×900) و mobile (810×1620) وأربعة ألواح صغيرة لكل واحد
  gallery/<مشهد>/     ٦ صور معرض 1600×1200 مع نسخ مصغّرة 720×540
logo/                 نسخ اللوغو بالألوان التي جرّبناها
tools/
  render_scene.py     يرسم المشاهد بمتصفح Edge مخفي ويبني الألواح الصغيرة والصور المصغّرة
  frame_server.py     سيرفر محلي يستقبل الكادرات ويحفظها، ويعرض المستودع على 8766
  bench.js            اختبار سرعة: يمرّر بالصفحة ويقيس الإطارات بالثانية والتوقفات
  run_bench.py        يشغّل الاختبار بنافذة Edge أو Chrome حقيقية ويكتب النتيجة في tools/bench.log
run-site.bat          يشغّل الموقع على ويندوز ويفتحه بالمتصفح
```

## تعديل النصوص أو الصفحات

عدّل `src/data/site.json` أو القوالب في `src/templates/`، ثم:

```bash
python -I src/build.py
```

## إعادة رسم مشهد

المشاهد لا تعمل في متصفح الزائر؛ هي مرسومة مسبقاً كصور، والصفحة تعرض الصورة المناسبة لموضع السكرول.
بعد أي تعديل على `src/scenes/`:

```bash
python -I tools/frame_server.py
```

ثم في طرفية ثانية (أسماء المشاهد: story cards incense sweets bags invitations cups stickers):

```bash
python -I tools/render_scene.py cards incense
```

`--what=film` للفيلم فقط، `--what=stills` لصور المعرض فقط.

## التشغيل محلياً

على ويندوز: دبل كليك على `run-site.bat`.

أو من أي طرفية (يحتاج Python):

```bash
python -m http.server 8765 --directory docs
```

ثم افتح `http://localhost:8765/`. أضف `#debug` لآخر الرابط لترى عدد الإطارات بالثانية.

## الأداء

لا يوجد 3D في متصفح الزائر. كل فيلم يصل أولاً بأربعة ألواح صغيرة (أولها وحده يغطي الفيلم كله بكل رابع كادر)،
ثم تأتي الكادرات الحادة من مكان القارئ. الكادرات تُفكّ خارج الخيط الرئيسي (createImageBitmap)، فلا يُرسم كادر قبل أن يكون جاهزاً.

قياس حقيقي على لابتوب ٢٠١١ (Intel HD Graphics 3000، شاشة 1366×768)، تمرير ١٤ ثانية:

| الطريقة | إطار/ثانية | توقفات طويلة | أطول توقف |
|---|---|---|---|
| بدون كادرات أصلاً | 39.7 | 0 | 0 |
| **كادرات JPG (المعتمد)** | **39.7** | **0** | **0** |
| فيديو H.264 | 39.7 | 1 | 62 ms |
| كادرات WebP | 34.7 | 10 | 401 ms |

لتجربة نت بطيء: `FRAME_SERVER_KBPS=130 FRAME_SERVER_RTT_MS=300 python -I tools/frame_server.py` ثم `python -I tools/run_bench.py 2 http://localhost:8766/docs/ chrome`.
